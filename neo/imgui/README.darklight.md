# Dear ImGui vendoring

Darklight vendors Dear ImGui **v1.92.6** from the official
[`ocornut/imgui`](https://github.com/ocornut/imgui) repository, tag commit
`6ded5230d043aa32c755e65c910c2af5002fb9f9`.

Included files are the Dear ImGui core and the official Win32/OpenGL2
backends used by DoomRadiant's separately double-buffered Blueprint editor
window. The upstream MIT license is preserved in `LICENSE.txt`.
